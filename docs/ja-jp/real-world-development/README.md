現実的なシナリオ、完成したアプリケーション、共有バックログを使って、ソフトウェア開発ライフサイクル全体で GitHub Copilot を活用します。変更の計画、コード作成、動作テスト、プルリクエストのレビュー、エージェントを使った作業管理を繰り返し実践します。

## シナリオ

あなたは、開発者向けテーマのボードゲーム向けクラウドファンディングを提供する架空の会社 Tailspin Toys に加わったばかりの開発者です。チームのバックログは GitHub Issue として登録済みで、すぐに着手できます。アクセシビリティやコーディング標準などの品質改善に加えて、フィルターやページネーションなどの機能開発も含まれています。

## 環境を選ぶ

GitHub Copilot は、どこで作業していても利用できます。開発方法に合った環境を選んでください。各ワークショップは個別のセットアップから始まり、共通の Tailspin Toys シナリオを使用します。

### [GitHub Copilot CLI][cli]

ターミナルでエージェント型アシスタントを使います。Plan と Autopilot モード、指示、スキル、カスタムエージェント、Playwright MCP、Agent Merge、便利なスラッシュコマンドを学びます。

### [GitHub Copilot app][app]

デスクトップアプリで、エージェントセッションの並列実行、セッションモードの切り替え、Canvas での共同作業、GitHub Issue とプルリクエストの管理を行います。

### [GitHub Copilot cloud agent][cloud]

GitHub Issue を非同期エージェントに割り当て、作業を案内し、進行状況を監視して、作成されたプルリクエストをレビューします。

### [Visual Studio Code][vscode]

Visual Studio Code と GitHub Codespaces で GitHub Copilot を使います。エディターを離れずに、Copilot Chat のエージェントモード、MCP サーバー、カスタムエージェントを活用します。
