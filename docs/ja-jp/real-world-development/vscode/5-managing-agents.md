GitHub Copilot をエージェント モードで使うと、コードベースを調べ、変更を提案してファイルを編集し、コマンドを実行します。この作業はローカル環境でリアルタイムに進むため、VS Code の Copilot Chat では各ツールの呼び出しやファイルの編集状況を確認できます。差分をインラインでレビューして個々の変更を採用または取り消し、エディターを離れずに追加プロンプトを送って作業を調整できます。

この演習では次の操作を行います。

- アクセシビリティ エージェントの作業をリアルタイムで監視します。
- 提案されたファイル変更をレビューして採用します。
- セッション中にエージェントへ指示を追加し、ハイ コントラストに加えてライト モードも作成します。

## シナリオ

[演習 4][previous-lesson]で使ったアクセシビリティ カスタムエージェントが、ハイ コントラスト モードを実装しています。作業中、デザイン チームから、既定のテーマが暗すぎると感じるユーザー向けのライト モードも追加してほしいという依頼がありました。新しい会話を始める代わりに、進行中のセッションに追加の指示を送ります。

## Copilot の進行状況を監視する

Copilot Chat ビューには、エージェントが行う各手順が表示されます。調べたファイル、実行したコマンド、提案された編集を確認できます。ファイル編集は差分と **Keep** / **Undo** の操作とともにインラインで表示されます。

1. 演習 4 で使った Copilot Chat ビューに戻ります。
2. エージェントの作業中にチャットをスクロールし、各ツール操作を確認します。ファイルの読み取りや編集、実行を求められたターミナル コマンドなどが表示されます。
3. ファイル編集の差分が表示されたら、次の操作を行います。
   - **Keep** を選択して変更を採用します。
   - **Undo** を選択して変更を取り消し、エージェントに再度作業してもらいます。
4. チャット上部の **Files changed** を開き、このセッション中に変更されたファイル全体を確認することもできます。

> [!NOTE]
> ターミナル コマンドの実行などで許可が必要な場合、エージェントは一時停止して **Allow** を表示します。内容を確認し、許可してもよいコマンドだけを承認してください。

5. エージェントがハイ コントラスト モードを実装し終えるまで待ちます。最後に変更内容の要約が表示されます。

## エージェントにライト モードを依頼する

ハイ コントラスト モードができたら、同じ会話でライト モードの切り替え機能を追加します。同じチャット セッションを続けるため、エージェントは前の作業のコンテキストを保持します。変更したコンポーネント、スタイル、local storage のパターンなどが含まれます。

1. Copilot Chat の入力欄に次の追加プロンプトを送信します。

   ```plaintext
   Nice work! Now add a light-mode toggle alongside the high-contrast toggle. Light mode should follow the same pattern — persist via local storage and be accessible from the same area of the UI. The user should be able to enable high-contrast and light mode independently.
   ```

2. エージェントは以前の変更を確認し、ライト モードの追加を提案します。
3. 変更ごとに差分をレビューし、**Keep** または **Undo** を選択します。
4. 望まない方向に進んだ場合 (たとえば切り替え UI を意図せずリファクタリングする場合) は、チャット入力欄の横にある **Stop** ボタンで停止してから、追加の説明を送ります。

> [!TIP]
> 進行中のセッションに指示を送ると、最初からやり直すより短時間で調整できます。「CSS を簡潔にし、セレクターの重複ではなく CSS 変数を使ってください」「3 つ目の切り替えを追加せず、既存の設定パネルにライト モードを組み込んでください」「両方の切り替えにキーボード ショートカットも追加してください」などの追加依頼を送れます。

## 作業内容をレビューする

作業をコミットする前に、エージェントが変更したすべてのファイルを確認します。

1. VS Code で **Source Control** ビューを開きます。
2. 変更されたファイルの一覧を確認します。Astro コンポーネント、スタイル、関連テストなどが含まれます。
3. 変更されたファイルをいくつか開き、差分を確認します。カスタムエージェントが適用した ARIA 属性、キーボード操作、セマンティック HTML、local storage による保存を確認します。
4. 問題がなければ **Source Control** パネルから変更をステージしてコミットします。次のレッスンでブランチを公開します。

## まとめと次のステップ

Copilot Chat のエージェント モードで進行中のセッションを監視し、各ファイルの編集をレビューし、変更を採用または取り消し、追加プロンプトを送ってコンテキストを保ったまま作業を拡張しました。

このレッスンでは、次の内容を学びました。

- エージェントの作業をリアルタイムで監視する方法
- 個々のファイル編集を採用または取り消す方法
- 追加プロンプトで進行中のセッションを調整する方法
